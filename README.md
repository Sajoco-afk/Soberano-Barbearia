# 👑 Soberano Barbearia

> Site institucional desenvolvido para a **Soberano Barbearia**, com foco em apresentar os serviços, valores, informações de contato e facilitar o agendamento de horários pelo WhatsApp.

## 📌 Sobre o projeto

O **Soberano Barbearia** é um projeto web criado como prática de desenvolvimento front-end. A página apresenta uma identidade visual voltada para uma barbearia e reúne, em um único site, informações sobre cortes, serviços, história, horários, localização e contato.

O projeto também demonstra o uso de links externos para facilitar o contato com o cliente e o acesso à localização da barbearia.

## ✨ Funcionalidades

* 🏠 Página inicial com apresentação da barbearia
* 💈 Catálogo de cortes e serviços
* 💰 Exibição dos valores dos serviços
* 📱 Botões de agendamento pelo WhatsApp
* 📖 Seção sobre a história da barbearia
* 🕘 Informações de horário de atendimento
* 📍 Link para localização no Google Maps
* 📲 Link para redes sociais
* 📱 Layout adaptado para diferentes tamanhos de tela

## 🛠️ Tecnologias utilizadas

* **HTML5** — estrutura e organização da página
* **CSS3** — estilização, layout e responsividade
* **Unsplash** — imagens utilizadas no projeto
* **WhatsApp** — integração para contato e agendamento
* **Google Maps** — localização da barbearia

## 🚀 Como executar

1. Clone este repositório:

```bash
git clone https://github.com/Sajoco-afk/Soberano-Barbearia.git
```

2. Entre na pasta do projeto:

```bash
cd Soberano-Barbearia
```

3. Abra o arquivo `index.html` no navegador.

> Não é necessário instalar dependências ou configurar um servidor para executar a versão atual do projeto.

## 📱 Agendamento

O site possui botões que direcionam o cliente para o WhatsApp da barbearia, permitindo solicitar um horário de atendimento de forma rápida.

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de praticar e demonstrar conhecimentos básicos de desenvolvimento web, principalmente:

* Estruturação de páginas com HTML5;
* Estilização com CSS3;
* Organização de conteúdo;
* Criação de navegação interna;
* Utilização de links externos;
* Construção de uma página comercial responsiva;
* Publicação e versionamento de projetos utilizando Git e GitHub.
